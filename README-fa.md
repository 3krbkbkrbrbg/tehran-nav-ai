# مسیریاب هوشمند تهران (Tehran Nav AI) 🇮🇷

یک اپلیکیشن مسیریابی اندرویدی نوشته شده با **Kotlin** و **Jetpack Compose** با قابلیت پشتیبانی از هوش مصنوعی (Gemini) و حالت‌های آفلاین.

## ویژگی‌ها
۱. **مسیریابی عادی**: اتصال به Google Directions API برای مسیریابی بین مبدا و مقصد.
۲. **مسیریابی هوشمند (AI)**: یکپارچگی با **Google Gemini** برای تشخیص نیت کاربر از طریق متن طبیعی (مثلاً "نزدیک‌ترین رستوران کجاست؟").
۳. **نقشه‌های آفلاین**: بستر آماده برای دانلود و مدیریت MapTiles آفلاین ایران (آماده اتصال به OSRM/MapLibre).
۴. **حریم خصوصی**: دریافت هوشمند دسترسی‌ها و ذخیره رمزنگاری‌شده کلیدهای API (EncryptedSharedPreferences).
۵. **طراحی بومی**: رابط کاربری متریال دیزاین ۳ کاملاً راست‌به‌چپ (RTL).

## نیازمندی‌های توسعه‌دهنده
- Android Studio Iguana / Jellyfish
- JDK 17+
- API Key برای Google Maps
- API Key برای Google Gemini

## ساختار پروژه (Milestone-based)
- `core/navigation`: کلاینت‌های Retrofit برای گرفتن مسیرها.
- `core/ai`: سرویس `GenerativeModel` جمینای برای پردازش پرامپت‌ها.
- `core/security`: مدیریت امن کلیدهای وارد شده توسط کاربر.
- `ui/screens`: صفحات اپ (Splash, Map, Settings, OfflineMaps) بر پایه Jetpack Compose.

## نحوه راه‌اندازی
۱. پروژه را در Android Studio باز کنید.
۲. برنامه را روی شبیه‌ساز یا گوشی واقعی نصب کنید.
۳. در اولین اجرا، دسترسی به موقعیت مکانی (GPS) درخواست می‌شود.
۴. از منوی کشویی به **تنظیمات** بروید و **کلید API گوگل مپ** و **جمینای** خود را وارد کنید تا هوش مصنوعی فعال شود.
۵. دکمه «حالت AI» را در نقشه روشن کرده و با زبان طبیعی با نقشه صحبت کنید!
